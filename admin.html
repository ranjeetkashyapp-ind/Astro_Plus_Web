Hosting / Deployment URL Settings

AstroPlus वेबसाइट और Admin Panel सामान्य Static HTML साइटों की तरह अलग-अलग प्रोजेक्ट में Publish हो सकते हैं। Cloudflare Pages, Netlify, GitHub Pages, Vercel, Firebase Hosting या किसी भी सामान्य Static Hosting का उपयोग कर सकते हैं। अभी astroplus.in या उसके subdomain की जरूरत नहीं है। यह सेटिंग केवल URLs सुरक्षित रखती है; Publish संबंधित Hosting Dashboard से होगा।

सामान्य वेबसाइट चलाने के लिए Backend API URL भरना जरूरी नहीं है। AI Astrologer की चुनी हुई AI API अलग AI सेटिंग में ही रखी जाएगी।

अभी कोई Deployment URL सेव नहीं है।

डेटा सेविंग मोड

अभी सामान्य वेबसाइट/Admin कार्य के लिए कोई अलग Backend API URL अनिवार्य नहीं है। यह HTML संस्करण ब्राउज़र के Local Storage में डेमो डेटा रखता है। अलग-अलग डिवाइस या अलग-अलग डोमेन के बीच साझा लाइव डेटा चाहिए होगा तो बाद में फ्री डेटाबेस/स्टोरेज विकल्प जोड़ा जा सकता है। AI Astrologer की AI API केवल AI सेटिंग में अलग से कॉन्फ़िगर होगी।

वेबसाइट डेटा कनेक्शन

AI और मानव दोनों की सामान्य प्रोफाइल जानकारी एक ही directory record schema में सेव होती है। वेबसाइट दोनों के लिए एक ही सार्वजनिक कार्ड/प्रोफाइल टेम्पलेट इस्तेमाल करेगी; फोटो, नाम, परिचय, विशेषज्ञता, अनुभव, भाषा और फीस उपलब्ध रिकॉर्ड के अनुसार दिखेंगे। AI/Human वर्गीकरण और AI तकनीकी कॉन्फ़िगरेशन केवल एडमिन के लिए हैं। अलग subdomain पर production sync के लिए backend API जोड़ना बाकी है।

मुख्य कंट्रोल

यह प्रोटोटाइप समान origin (एक ही scheme + host + port) पर Local Storage से वेबसाइट कार्ड/प्रोफाइल डेटा सिंक करता है। admin.astroplus.in और astroplus.in अलग origin हैं; इनके बीच वास्तविक लाइव सिंक के लिए साझा backend API/database आवश्यक है।। वास्तविक सर्वर डेटाबेस, सुरक्षित लॉगिन, Google Form से स्वतः आवेदन प्राप्त करना और लाइव भुगतान अभी जुड़े नहीं हैं।

सुरक्षा और Live Activation

यह Admin UI API credentials को browser Local Storage में सेव नहीं करता। Save/Test बटन authenticated Backend endpoints को request भेजते हैं। Backend में encrypted secret storage, provider-specific order/payment creation, webhook signature/checksum verification, payment status callback और wallet crediting पूरा होने के बाद ही Gateway को Live करें। Gemini के लिए भी server-side key storage और model request proxy आवश्यक है।

ध्यान दें: Razorpay, Cashfree, PayU और PhonePe में केवल एक सामान्य API key पर्याप्त नहीं होती; हर provider के अपने merchant credentials और account activation की जरूरत होती है।

Platform Settings

Payment Gateway Connections

यह form अभी connection details का UI है। वास्तविक save/test/connect action के लिए authenticated backend endpoint और provider-specific credentials आवश्यक हैं।

🌐 AI Global Model Control — सभी AI ज्योतिषियों के लिए साझा मॉडल

एक ही Gemini या अन्य चुना हुआ मॉडल सभी AI प्रोफाइल में साझा किया जा सकता है। हर प्रोफाइल का नाम, फोटो, व्यक्तित्व, System Prompt और ज्योतिष ज्ञान अलग रहेगा। Gemini API Key को सुरक्षित Backend Secret Manager में एक बार सेव करें; HTML या Local Storage में Secret रखना सुरक्षित नहीं है। AI profiles केवल अलग Prompt/Identity रखेंगी और shared engine इस्तेमाल करेंगी।

कनेक्शन टेस्ट तभी सफल हो सकता है जब Backend API उपलब्ध हो। अभी यह सेटिंग UI/कॉन्फ़िगरेशन रिकॉर्ड है।

फोटो को एक उंगली / माउस से खिसकाएँ। मोबाइल पर दो उंगलियों को पास-दूर करके ज़ूम करें। माउस व्हील से भी ज़ूम कर सकते हैं।
